# Зургууд хэрхэн ажилладаг

## Нүүр хуудасны том зургууд — админаас удирдана
Нүүр (landing) болон нэвтэрсний дараах home-ийн том зургууд **админ панелаас**
ирдэг:

1. `/admin/content` → кино засах
2. **Дэвсгэр (16:9)** зураг оруулах (жишээ нь 1920×1080+)
3. **«Онцлох»** чагт идэвхжүүлээд Хадгалах

→ Тухайн кино нүүрний carousel-д зурагтайгаа гарна. Дэвсгэргүй онцлох кино
постероороо гарна.

## posters/ ба backdrops/ — seed киноны локал зургууд
Туршилтын (seed) кинонуудад гараар зураг өгөх бол:

- `posters/<slug>.jpg` — босоо постер, 2:3 (жишээ нь 600×900)
- `backdrops/<slug>.jpg` — өргөн дэвсгэр, 16:9 (жишээ нь 1920×1080)
- Slug-ууд: `john-wick-chapter-4`, `godzilla-minus-one`, `the-bear`

## uploads/ — админ панелийн хуулсан файлууд
R2 холбогдоогүй үед админаас оруулсан бүх зураг/видео энд автоматаар
хадгалагдана. Гараар бүү засаарай.
